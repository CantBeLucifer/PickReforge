# PickReforge

This mod let's you choose the outcome of reforges from the Goblin Tinkerer NPC.

The list is sorted by rarity, you can select multiple items in the list to create a custom RNG pool.

[![demo](https://i.postimg.cc/BnPwmL20/Animation.gif)](https://postimg.cc/CRYN1KvP)

The price of reforge is a custom calculation.

- If you select only top tier e.g. Legendary, the price will be slightly less than the expected cost of vanilla RNG.

- If you select only one of the lower tiers, the price will be much cheaper than expected cost of vanilla RNG.

- If you select more than one, the price will be dictated by the highest value Prefix, but it will still be divided by all options.

Example: If you select Legendary and 1 other Prefix, the price will be half if you just selected Legendary.

### Config Options

#### Disable Custom Price
If you don't want a 'fair' price, you can turn the custom price off and just pay for 1 vanilla cost reforge.
#### List Length
You can change how many items appear at one time in the Prefix list.
